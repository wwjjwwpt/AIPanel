# 瞬贴

一个原生 macOS 菜单栏剪贴板、截图历史与显示器镜像工具。

## 功能

- 自动记录文本、链接、图片和文件剪贴板
- 首次启动选择截图归档工作区，自动创建“瞬贴截图归档”目录
- 自动归档 macOS 系统截图（默认监控桌面，可在设置中更换来源）
- `⌘⇧V` 全局快捷键呼出
- `⌃⇧A` 框选截图，直接在选区原位置标注，背景透明，工具栏紧贴选区；支持画笔、矩形、圆圈、箭头、原位输入文字、颜色、粗细和撤销／重做
- 截图编辑器中 `⌘C` 完成并复制，`⌘S` 选择位置保存 PNG（同时复制、加入历史和归档），`Esc` 取消；导出保留原始像素尺寸
- 输入搜索、方向键选择、回车复制并返回原应用，再按 `⌘V` 粘贴
- 固定和删除历史记录，数据仅保存在本机
- 可选开机启动
- 主面板「显示器镜像」标签：选择主显示器与镜像目标，一键开/关屏幕镜像（需外接显示器，自动响应显示器插拔）

## 构建

只需要 macOS Command Line Tools：

```bash
./scripts/build-app.sh
```

构建结果位于 `dist/瞬贴.app`。将它拖到 `/Applications` 后启动，以保证“开机启动”正常注册。

没有开发者签名证书时，可用 `SIGNING_IDENTITY=- ./scripts/build-app.sh` 构建本机试用版本。
截图标注与导出回归检查：`zsh scripts/test-screenshot-editor.sh`（无需安装 Xcode）。

macOS 14 及以上通过 ScreenCaptureKit 在应用内截图；macOS 13 使用系统截图工具。
本机试用版使用临时签名，重新构建后可能需要重新授权屏幕录制：在系统设置中移除旧的瞬贴，重新添加 `/Applications/瞬贴.app` 并开启权限，然后完全退出、重开应用。使用固定的开发者签名证书可避免更新时因签名身份变化导致的授权失配。

## 首次使用

1. 打开 `瞬贴.app`，菜单栏会出现剪贴板图标。
2. 按 `⌘⇧V` 呼出历史。
3. 第一次启动时选择一个归档位置，瞬贴会在里面创建“瞬贴截图归档”。
4. 回车或双击一条记录后，瞬贴会复制内容并返回原应用；按正常的 `⌘V` 粘贴，无需辅助功能权限。
5. 如系统截图不保存在桌面，请在设置中选择实际的截图来源文件夹。

历史数据保存在 `~/Library/Application Support/PasteboardMemory`，不会上传网络。
