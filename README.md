# 瞬贴

一个原生 macOS 菜单栏剪贴板与截图历史工具。

## 功能

- 自动记录文本、链接、图片和文件剪贴板
- 首次启动选择截图归档工作区，自动创建“瞬贴截图归档”目录
- 自动归档 macOS 系统截图（默认监控桌面，可在设置中更换来源）
- `⌘⇧V` 全局快捷键呼出
- 输入搜索、方向键选择、回车复制并返回原应用，再按 `⌘V` 粘贴
- 固定和删除历史记录，数据仅保存在本机
- 可选开机启动

## 构建

只需要 macOS Command Line Tools：

```bash
./scripts/build-app.sh
```

构建结果位于 `dist/瞬贴.app`。将它拖到 `/Applications` 后启动，以保证“开机启动”正常注册。

## 首次使用

1. 打开 `瞬贴.app`，菜单栏会出现剪贴板图标。
2. 按 `⌘⇧V` 呼出历史。
3. 第一次启动时选择一个归档位置，瞬贴会在里面创建“瞬贴截图归档”。
4. 回车或双击一条记录后，瞬贴会复制内容并返回原应用；按正常的 `⌘V` 粘贴，无需辅助功能权限。
5. 如系统截图不保存在桌面，请在设置中选择实际的截图来源文件夹。

历史数据保存在 `~/Library/Application Support/PasteboardMemory`，不会上传网络。
